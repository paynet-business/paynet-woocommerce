== Description ==
Accept Credit Cards, Paynet Wallet, Webmoney, Qiwi, Yandex, Bitcoin, Cash-in terminals, and more all in one plugin for free!

= Boost conversion by offering product and cart page checkout =
Paynet for WooCommerce is made to supercharge your conversion rate by decreasing payment friction for your customer.

= Features =
- Accept Credit Cards
- Paynet Wallet
- Webmoney
- Qiwi
- Yandex
- Cash-in terminals
- 3DS 2.0
